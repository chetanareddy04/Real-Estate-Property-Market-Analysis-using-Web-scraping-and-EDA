#  Real Estate Property Market Analysis – Hyderabad

##  Project Overview
A Web Scraping and Exploratory Data Analysis (EDA) project focused on analysing residential flat listings in Hyderabad collected from MagicBricks.

Using Python and Selenium, property data was collected and analysed to understand pricing patterns, property characteristics, and locality-wise variations.

##  Business Problem
Hyderabad's real estate market offers properties across different localities, sizes, and price ranges. Comparing these listings and understanding their pricing patterns can be challenging for prospective buyers.

This project analyses real-world property listings to uncover meaningful market trends and pricing insights.

##  Project Objectives
- Collect residential property data using web scraping.
- Clean and prepare the collected dataset.
- Explore property distributions and pricing patterns.
- Analyse locality-wise and BHK-wise price variations.
- Investigate relationships between property features.
- Apply statistical hypothesis testing to validate observations.

##  Dataset
- **Source:** [MagicBricks – Flats for Sale in Hyderabad](https://www.magicbricks.com/flats-in-hyderabad-for-sale-pppfs)
- **Location:** Hyderabad, Telangana
- **Property Category:** Residential Flats for Sale
- **Final Dataset:** 1,263 records × 10 features

 Key Analysis
- BHK-wise property distribution
- Furnishing and area analysis
- Property price and price-per-sq.-ft. analysis
- Locality-wise price comparison
- Correlation analysis
- Welch's t-test and One-Way ANOVA

 Tools & Technologies
Python | Selenium | Pandas | NumPy | Matplotlib | Seaborn | SciPy

 Key Findings
- 3-BHK properties formed the largest share of listings.
- Most properties were between 1,000 and 2,000 sq. ft.
- Kokapet recorded the highest average listing price among the selected localities.
- Property prices varied across localities and configurations.
